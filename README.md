# Simba Holidays Expense Manager — Releases

This repository hosts auto-update releases for the **Simba Holidays Expense Manager** Windows desktop application.

## Auto-Update
The app uses `electron-updater` and reads `latest.yml` from this repository's release assets to detect and download updates automatically.

## Manual Download
Download the latest release from the [Releases](https://github.com/Tjimmer/expense-manager-releases/releases) page.

### Installation
1. Download `SimbaHolidays-ExpenseManager-*-win-portable.zip`
2. Extract to a folder of your choice
3. Run `Simba Holidays Expense Manager.exe`

**Default credentials:** username `admin` / password `admin123`
